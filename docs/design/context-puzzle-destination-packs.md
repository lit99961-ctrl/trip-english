# 语境解谜与目的地内容包设计

## 产品目标

Trip English 帮助英语基础较弱的学习者，在旅行中完成简单、真实、独立的交流。游戏化设计只服务于三个学习结果：

1. 能轻松说出解决当前问题所需的短句。
2. 能从对方的回答中听懂意图和关键词。
3. 能看懂标牌、菜单、车票和消息中的少量常用词。

系统不以语法完整、口音标准或语音识别分数作为通关门槛。只要表达包含足够的功能性关键词，并且学习者能够判断对方的核心意思，就算交流成功。

## 设计原则

### 口语和听力优先

- 每个任务必须包含听力判断、跟读和一次无完整答案的主动表达。
- 每个新短语先听、再看、再说，避免只靠阅读完成课程。
- 训练时间约 70% 用于听和说，20% 用于语境阅读，10% 用于选择或轻量解谜。
- 用户应能在进入任务后的三次点击内开始第一次开口练习。

### 轻量语境解谜

借鉴语言解谜游戏的观察—猜测—验证循环，但使用真实英语：

1. 显示一个清晰的旅行场景、标牌或人物动作。
2. 播放一句很短的英语，让玩家判断对方想表达什么。
3. 玩家从语境猜一个关键词，并记录到“旅行者手账”。
4. 系统通过图片、中文关键词或例句逐级验证。
5. 玩家立即用这个词完成一句真实口语任务。

解谜不能成为学习障碍。第一次错误提供视觉线索，第二次错误提供中文关键词，第三次直接展示答案并进入跟读。任何玩家都能继续前进。

项目只借鉴抽象的学习循环，不复制其他游戏的美术、符号、角色、故事或具体谜题。

### 小词汇量，高复用

- 每个任务只引入 3–5 个新词。
- 一个新词至少在听力、阅读和口语中各出现一次。
- 优先复用机场、酒店、交通、餐厅和求助等通用词。
- 专有地名只作为目的地线索，不要求记忆或掌握。

### 功能性成功标准

- 语音识别只提供反馈，不决定玩家能否继续。
- 忽略冠词、轻微语法错误和口音差异。
- 重点检查地点、数量、动作、时间等功能关键词。
- 每个任务至少提供三种简短的对方回答，训练同一意图的不同说法。
- 识别不可用或离线时，使用录音回听和“说顺了 / 还不熟”自评。
- 选择题只能记为“已练习”，无提示主动表达才能进入掌握判断。

## 目的地内容包

应用由一个通用核心课和多个可选目的地包组成。

### 通用核心课

覆盖机场、酒店、餐厅、火车、问路、购物和紧急求助。核心课负责高频表达和恢复句，例如：

- “Could you say that again slowly?”
- “Where is …?”
- “I need help.”
- “Is this the right train?”

### 目的地包

目的地包只增加当地真正不同的场景、词汇和听力变化。每个国家首版包含三个短任务，复用核心课能力，避免重复教学。

建议顺序：

1. 法国
2. 西班牙
3. 加拿大
4. 新西兰
5. 冰岛

用户可以选择一个或多个目的地。首页只显示已选择的内容，离线缓存也只下载对应资源。

## 法国样板包

### 任务一：巴黎地铁出口

- 语境词：exit、line、change、direction
- 听力目标：听懂线路、换乘和出口方向
- 口语目标：“Which exit is for the Louvre?”
- 解谜线索：地铁图、出口箭头和人物指向

### 任务二：咖啡馆点单

- 语境词：menu、still water、bill、takeaway
- 听力目标：听懂堂食或外带、饮品选择和价格
- 口语目标：“I would like this, please. To take away.”
- 解谜线索：菜单、杯子和账单

### 任务三：火车临时变更

- 语境词：delayed、platform、cancelled、replacement
- 听力目标：判断列车晚点、换站台或取消
- 口语目标：“Has the platform changed?”
- 解谜线索：出发屏、颜色变化和工作人员动作

## 单个任务流程

每个任务控制在 8–10 分钟：

1. **看场景并听一句（1 分钟）**：先不给完整字幕，可随时重播或降速。
2. **判断核心意思（1 分钟）**：二选一或三选一，只检查意图。
3. **发现 3–5 个词（2 分钟）**：根据图片和上下文猜词，加入手账。
4. **跟读两次（2 分钟）**：正常速度一次、慢速一次，允许回听自己的录音。
5. **独立完成交流（2 分钟）**：只显示中文目标或场景提示，不显示完整英文答案。
6. **读一个真实文本（1 分钟）**：标牌、菜单或出发屏，只问一个关键问题。

三关可以组成一次约 30 分钟正式训练。系统从其中抽取词汇和短句，生成每天三次、每次约两分钟的碎片复习。

## 旅行者手账与奖励

- 手账记录已经通过语境验证的词，而不是展示完整词典列表。
- 每个词显示英文、中文、发音和一个旅行例句。
- 城市印章表示完成故事章节，不代表已经掌握全部英语。
- 掌握状态继续由无提示主动表达和间隔复习决定。

## 内容包接口

每个目的地包需要声明：

- 唯一 ID、国家、城市和显示名称
- 三个任务及其听力、口语和阅读目标
- 每个任务的 3–5 个新词和可复用核心词
- 可按正常和慢速播放的固定音频资源
- 离线资源清单
- 难度、提示级别和无提示成功条件

构建时自动检查重复 ID、缺失翻译、超出词汇上限、无音频引用和未纳入离线缓存的资源。

## 隐私与开源边界

- 内容不得包含真实旅行日期、订单、酒店、航班、证件号码或联系方式。
- 示例姓名使用明显的虚构角色。
- 目的地路线来自一般旅游场景，不对应某位用户的真实行程。
- 内容贡献需遵循相同的数据结构和自动校验规则。

## 首阶段验收标准

- 现有意大利和瑞士进度可以继续读取。
- 用户能选择或取消法国内容包，不影响核心课。
- 法国三关均满足 3–5 个新词、听力判断、两次跟读和无提示表达。
- 玩家无法仅通过选择题获得“已掌握”。
- 在线识别失败或离线时仍能完成全部任务。
- 目的地资源可以独立缓存，未选择的内容不强制下载。
- 手机端保持每屏一个主要操作，支持键盘、读屏和大字体。
