# 在 iPhone 安装 Trip English

这个版本不需要账号或服务器。学习进度、录音和收藏保存在当前设备的浏览器中；请定期在“进度”页下载备份。

## 发布到 GitHub Pages

发布需要你授权使用自己的 GitHub 仓库；本地实现完成并不代表已经上传或公开。

1. 在 GitHub 新建仓库，并把本项目连接为远程仓库。
2. 将当前分支合并到 `main`，再推送 `main`。
3. 在仓库 **Settings → Pages** 中把 Source 设为 **GitHub Actions**。
4. 等待 “Deploy GitHub Pages” 工作流成功。
5. 打开工作流给出的 HTTPS 地址，通常是 `https://你的用户名.github.io/仓库名/`。

## 添加到手机桌面

1. 用 iPhone 的 Safari 打开上述 HTTPS 地址。
2. 点 Safari 的“分享”，选择“添加到主屏幕”。
3. 从桌面图标打开应用，并保持联网直到顶部显示“离线内容已就绪”。
4. 打开“急救箱”朗读一句英文，确认设备运行时语音可用。
5. 开启飞行模式，完全退出再重新打开桌面应用；顶部应显示“离线可学习”，课程、词典和救命句卡仍可使用。设备已安装可用英语语音时，朗读通常也可离线使用。

## 十多天冲刺用法

每天先在首页点“开始 / 继续今天的 30 分钟训练”。计划最多加入一个新场景，其余位置用已经学过的挑战或 2 分钟复习补齐，更容易坚持。

第一次打开应用可以直接学习，不必先做 2 分钟小游戏。进入酒店、餐厅、问路买票、意大利高铁、瑞士山区交通、超市或紧急求助时，先一次学完 16 句：8 句是自己可能要说的，8 句是对方可能说的。每句都能正常或慢速播放；“我要说”的句子可以录音回听。第 5、10、15 句后只做轻松回顾，不计分。中途退出后重新打开，会从上次一句继续。

学完第一组内容、准备进入正式口语挑战时，应用才会请你完成一次 2 分钟难度校准，用来决定后续给多少提示。校准不是学习内容的前置门槛。

学完后再次进入同一场景，优先点“快速复习关键句”；时间紧或已经熟悉时可点“直接挑战”。早晨、午间和晚上仍可分别做一次 2 分钟复习。不方便出声时只听、阅读或长按选择英文即可。

在线时可使用浏览器语音识别；离线时应用会自动改为录音回听与“说顺了 / 还不熟”自评，不会阻止继续学习。

进度页中的“已学”不等于“掌握”：只有无提示说出和完成场景，才会进入更高等级。这能避免出发前产生虚假的熟练感。
